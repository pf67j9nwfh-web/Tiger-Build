Almost done

Tiger Build Relay 1.4 is installed at /usr/local/tiger-build-relay. No API keys were included. Setup was run for the account that was logged in; see SETUP-RESULT.txt in that folder.

  1. Make an ssh-rsa key and install it on your Tiger Mac, as described in /usr/local/tiger-build-relay/RELEASE.txt.
  2. As your own user, run /usr/local/tiger-build-relay/scripts/setup.sh. The first run writes ~/Library/Application Support/Tiger Build Relay/config.sh. Set TIGER_HOST (the Tiger Mac's address) and TIGER_USER (the account on it).
  3. Run setup.sh again. It starts the relay and prints the relay's address, port and token. Open Tiger Build Relay from the Applications folder.
  4. On the Tiger Mac, open Tiger Build, then Preferences. Enter the address, port and token, and click Test Connection.
  5. Add API keys in the same window or in the Tiger Build Relay app, as many or as few as you use. Workspace ID and Local API key are optional.

Keys can also go in /usr/local/tiger-build-relay/.env; see .env.example. These steps are repeated in /usr/local/tiger-build-relay/ENV-SETUP.txt.
