Create the .env file

Tiger Desk is installed at /usr/local/tiger-desk. No API keys were included.

The same steps are saved at /usr/local/tiger-desk/ENV-SETUP.txt.

  1. In Terminal, create the file and open it: 
    sudo cp /usr/local/tiger-desk/.env.example /usr/local/tiger-desk/.env
sudo chmod 600 /usr/local/tiger-desk/.env
sudo nano /usr/local/tiger-desk/.env
  2. Paste a key after the name, with no spaces around the equals sign. Leave a line blank when you are not using that service.
    • XAI_API_KEY for Grok
    • OPENAI_API_KEY for ChatGPT
    • ANTHROPIC_API_KEY for Claude
    • ANTHROPIC_WORKSPACE_ID when the Claude key is not tied to one workspace
    • MISTRAL_API_KEY for Mistral
    • MUSE_API_KEY for Muse
    • GEMINI_API_KEY for Gemini
    • LOCAL_MODEL_URL for LM Studio on this Mac. The sample value is http://127.0.0.1:1234/v1
    • LOCAL_API_KEY only if that local server requires a key
  3. Tell the relay which Power Mac to use. The first time you run setup, it writes ~/Library/Application Support/TigerDesk/config.sh. Set TIGER_HOST to the Power Mac, TIGER_USER to the account there, and TIGER_KEY and TIGER_KNOWN to an ssh-rsa key that Mac accepts. Leave REMOTE_COMMANDER as $HOME/ppc-commander/ppc_commander.py.
  4. As your own user, not with sudo: 
    /usr/local/tiger-desk/scripts/setup.sh
  5. Check the relay: 
    curl http://127.0.0.1:8765/health
    A working relay answers ok grok-4.7.
