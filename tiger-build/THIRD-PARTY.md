# Third-party data in the app

- **`cacert.pem`**: the Mozilla CA certificate list (as published by curl at https://curl.se/ca/cacert.pem), used to check the certificate of every HTTPS server. Licence: MPL-2.0 (the list itself comes from Mozilla's certificate store). Replace the file with a newer copy to update the trusted roots; nothing else changes.
- **`Emoji.pack`**: Twemoji's 72x72 emoji pictures packed into one file by `scripts/pack-emoji.c` (instructions at the top of that file). Licence: CC-BY 4.0, text in `Emoji-LICENSE.txt`, which is also copied into the app. Graphics copyright Twitter, Inc. and other contributors (the jdecked/twemoji fork).
- **`prices-seed.json`**: starting model prices, generated by `scripts/make-prices.m`.

The libraries (mbedTLS, libwebp, libde265, libaom) are in `third_party/`, each with its own README.
