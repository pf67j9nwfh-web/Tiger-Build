Tiger Build 1.1
Setup for people who only download the installation packages

You need two computers on the same network:

  TigerDesk-1.1.pkg     the current Mac. This is the relay.
  TigerBuild-1.1.pkg    the Power Mac running Mac OS X 10.4. This is the chat app
                        and ppc-commander.

Install Tiger Desk first. Neither package contains API keys. The chat app
does not find the relay until you write the address file in the Power Mac
section below.

Tiger cannot open modern encrypted web connections, and it is an old system.
Use this on a network you trust.


On the current Mac
------------------

Install Python 3, then open TigerDesk-1.1.pkg. It puts the relay in
/usr/local/tiger-desk. The same steps are on the installer's last screen and
in /usr/local/tiger-desk/ENV-SETUP.txt.

Create the key file and fill in only the services you use. Leave the others
blank.

  sudo cp /usr/local/tiger-desk/.env.example /usr/local/tiger-desk/.env
  sudo chmod 600 /usr/local/tiger-desk/.env
  sudo nano /usr/local/tiger-desk/.env

  XAI_API_KEY                Grok
  OPENAI_API_KEY             ChatGPT
  ANTHROPIC_API_KEY          Claude
  ANTHROPIC_WORKSPACE_ID     only if the Claude key is not tied to one workspace
  MISTRAL_API_KEY            Mistral
  MUSE_API_KEY               Muse
  GEMINI_API_KEY             Gemini
  LOCAL_MODEL_URL            a local server on this Mac, such as LM Studio.
                             The sample is http://127.0.0.1:1234/v1
  LOCAL_API_KEY              only if that local server requires a key

There should be no spaces around the equals sign.

Make an ssh-rsa key. Tiger's SSH software cannot use a newer key type. Leave
the passphrase empty so the relay can start at login.

  mkdir -p ~/.ssh
  ssh-keygen -t rsa -b 2048 -f ~/.ssh/ppc_tiger_rsa -N ""

Copy the sample Power Mac config into place and edit it:

  mkdir -p ~/Library/Application\ Support/TigerDesk
  cp /usr/local/tiger-desk/config.example.sh \
    ~/Library/Application\ Support/TigerDesk/config.sh

Set TIGER_HOST to the Power Mac's address and TIGER_USER to the account
there. Leave these lines as they are:

  TIGER_KEY="$HOME/.ssh/ppc_tiger_rsa"
  TIGER_KNOWN="$HOME/.ssh/ppc_tiger_known_hosts"
  REMOTE_COMMANDER='$HOME/ppc-commander/ppc_commander.py'

REMOTE_COMMANDER stays in single quotes. The Power Mac fills in its own home
directory.

After Tiger Build is installed and Remote Login is on, accept the Power Mac's
host key and install your public key. Replace the user and address:

  ssh \
    -o HostKeyAlgorithms=ssh-rsa \
    -o PubkeyAcceptedAlgorithms=ssh-rsa \
    -o KexAlgorithms=diffie-hellman-group14-sha1,diffie-hellman-group1-sha1 \
    -o Ciphers=aes128-cbc,3des-cbc \
    -o MACs=hmac-sha1 \
    -o UserKnownHostsFile="$HOME/.ssh/ppc_tiger_known_hosts" \
    youruser@192.168.1.20 \
    'mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys' \
    < ~/.ssh/ppc_tiger_rsa.pub

Type yes when asked to trust the host key, then type that account's password.
This is the only time the password is needed.

Start the relay from Terminal, as your own user:

  /usr/local/tiger-desk/scripts/setup.sh
  curl http://127.0.0.1:8765/health

A working relay answers:

  ok grok-4.7

It listens on port 8765 and starts again at login. If this Mac asks whether
to allow incoming connections for Python, allow them. The log is:

  ~/Library/Application Support/TigerDesk/relay.log

Find the address the Power Mac should use. That is the address on the same
network as the Power Mac. 127.0.0.1 is only this Mac talking to itself.

  ipconfig getifaddr en0


On the Power Mac
----------------

Open TigerBuild-1.1.pkg and enter an administrator password. That installs
Tiger Build in /Applications and copies ppc-commander to:

  ~/ppc-commander/ppc_commander.py

It also turns on Remote Login when it can. If it cannot, turn on Remote Login
in System Preferences, Sharing.

Point the app at the relay. One line, with the current Mac's address:

  mkdir -p "$HOME/Library/Application Support/Tiger Build"
  echo "http://192.168.1.20:8765" > "$HOME/Library/Application Support/Tiger Build/server.txt"

Open Tiger Build from the Applications folder in Finder. Do not launch the
program inside the app package from Terminal.

Chats stay on the Power Mac. Keys stay in .env on the current Mac. In the
app, pick a model from the menus. A model whose key was left blank returns an
error for that chat and leaves the others usable.


Connect by hand
---------------

These steps use the relay and ppc-commander without opening Tiger Build.
Finish the current-Mac setup above first, including .env, config.sh, the
ssh-rsa key, and setup.sh. The health check must already answer ok grok-4.7.

There are two different connections.

1. Call the relay over HTTP. The relay calls the model, and when you leave
   tools on it runs ppc-commander on the Power Mac for you.

2. Attach a program straight to ppc-commander. That program gets the Power
   Mac file and shell tools. It does not get the chat models. The relay is
   not involved.


Shell on the Power Mac
----------------------

From the current Mac:

  /usr/local/tiger-desk/ppc-commander/bin/ppc-ssh

That opens a normal shell on the Power Mac. One command and no shell prompt:

  /usr/local/tiger-desk/ppc-commander/bin/ppc-ssh 'ls'

ppc-ssh reads TIGER_HOST, TIGER_USER, and the key paths from:

  ~/Library/Application Support/TigerDesk/config.sh


Chat through the relay
----------------------

On the current Mac:

  curl http://127.0.0.1:8765/health

From any other computer that can reach this Mac, use the network address
instead of 127.0.0.1.

A single reply, with ppc-commander turned off:

  curl -sS http://127.0.0.1:8765/v1/chat \
    -H 'Content-Type: application/json' \
    -d '{"provider":"grok","model":"grok-4.7","tools":false,"messages":[{"role":"user","content":"Say hello in one sentence."}]}'

The same call with tools turned on. The model can then read files and run
commands on the Power Mac:

  curl -sS http://127.0.0.1:8765/v1/chat \
    -H 'Content-Type: application/json' \
    -d '{"provider":"grok","model":"grok-4.7","tools":true,"messages":[{"role":"user","content":"What is in my home directory on the Power Mac?"}]}'

provider is one of: grok, chatgpt, claude, mistral, muse, gemini, local.
model is a model id that provider can call, such as grok-4.7 or gpt-5.5.
If you omit model, the relay uses its default for that provider.
messages is a list of user and assistant texts. The last one must be from
the user. tools is true unless you set it to false.

The answer comes back as plain text when the model is finished.


An MCP client on ppc-commander
------------------------------

Point the client's MCP command at:

  /usr/local/tiger-desk/ppc-commander/bin/ppc-commander-ssh

Give it no arguments. It reads the same config.sh, connects to the Power Mac
with the ssh-rsa key, and starts:

  ~/ppc-commander/ppc_commander.py

The program speaks MCP on its standard input and output. Leave that stream
alone. A shell prompt or a log line on that output breaks the connection.

For a client that asks for a command and arguments separately, the command
is the path above and the argument list is empty. The working directory can
be your home directory.

A client on another computer cannot run that script unless that computer has
the ssh-rsa key, config.sh, and a copy of ppc-commander-ssh. The usual place
to run the MCP client is the current Mac where Tiger Desk is installed.
